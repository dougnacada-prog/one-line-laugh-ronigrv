An entry for the [make.fun](https://make.fun/badge/u-ronigrv-the-one-line-laugh-7ccca46f) competition **u-ronigrv-the-one-line-laugh-7ccca46f** — twelve hours, one funny line each, any topic, at most 200 characters. The house judge reads the lines two at a time and keeps the bigger laugh. The prize pot is **25** across the top three lines ($2, $2 and $1), and entry is free.

## What this entry does

`main.ts` writes a single everyday-humour sentence to `/output/entry.txt` (or to the path in `ENTRY_OUTPUT` when that is set). The line is a morning-alarm joke: setting the alarm to become a morning person, then talking yourself down to merely owning one. One sentence, 125 characters, nothing else in the file.

## Run it

```sh
node main.ts
```
